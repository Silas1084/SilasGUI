# Silas 月影安全工具扫描器 - GUI 使用说明

> 本文档面向初次使用 Silas GUI 的用户，用最简洁的方式说明每个功能。

---

## 一、这款软件能做什么？

Silas 是一款 **Web 安全扫描工具**，可以帮你：

- 发现目标网站的子域名
- 识别目标网站使用了什么 Web 框架/组件/服务（指纹识别）
- 检测目标是否存在已知安全漏洞（POC 检测）

一句话总结：**输入一个目标，开启对应开关，Silas 就会帮你扫描并输出结果。**

---

## 二、主界面长什么样？

打开 `SilasGUI.exe` 后，你会看到：

| 区域 | 作用 |
|---|---|
| 顶部标签栏 | 切换功能模块，目前主要使用 **"Web扫描"**。 |
| 输入框 | 填写你要扫描的目标。 |
| ⬆ 上传文件 | 批量导入目标（仅支持域名）。 |
| 右侧任务列表 | 点击开关启动/停止扫描任务。 |
| 中间主区域 | 显示扫描动画、进度和最终结果。 |

---

## 三、输入框支持哪些目标？

在输入框中可以填写以下内容：

| 类型 | 示例 | 一句话说明 |
|---|---|---|
| 域名 | `example.com` | 最常用的扫描目标。 |
| URL | `http://example.com` | 带 http/https 的域名。 |
| 单个 IP | `192.168.77.123` | 只扫描这一台主机。 |
| IP + 端口 | `192.168.77.123:8083` | 扫描指定 IP 的指定端口。 |
| CIDR | `192.168.77.0/24` | 扫描整个网段，自动展开成 254 个 IP。 |
| IP 段 | `192.168.77.1-192.168.77.100` | 扫描指定范围内的所有 IP。 |

> ⚠️ **注意**：IP / IP:端口 / CIDR / IP 段 **仅支持"指纹识别"和"POC检测"** 任务。
> "快速扫描"和"子域名扫描"只支持域名。

---

## 四、右侧任务列表怎么用？

点击任务右侧的开关即可启动，再次点击停止。

| 任务 | 一句话说明 |
|---|---|
| **快速扫描** | 一键跑完"子域名 → 存活探测 → 指纹识别 → POC检测"完整流程。 |
| **子域名扫描** | 爆破并收集目标域名下的子域名。 |
| **指纹识别** | 识别目标网站使用的框架、CMS、中间件等组件。 |
| **POC检测** | 检测目标是否存在已知漏洞。 |

---

## 五、指纹联动 POC（重点新功能）

这是本次新增的核心功能：**指纹识别完成后，自动询问你是否要针对识别结果跑 POC。**

### 使用步骤

1. 在输入框填写 IP 或域名，例如 `192.168.77.123`。
2. 点击右侧 **"指纹识别"** 开关启动扫描。
3. 等待扫描完成，界面会弹出一个窗口询问：
   - **是**：针对识别到的指纹结果，自动运行相关 POC。
   - **否**：只显示指纹识别结果，不运行 POC。
4. 如果选择"是"，系统会自动启动 POC 检测，且只跑与命中指纹相关的 POC。

### 也可以手动触发

在指纹识别结果页右上角，有一个按钮：

> **对命中结果执行POC检测**

- 如果本次指纹识别**没有命中任何指纹**，该按钮会灰显。
- 点击后会和弹窗选"是"效果一样，自动启动针对性 POC 检测。

---

## 六、结果页怎么看？

每个任务会生成一个结果标签页，显示在界面上方。

### 普通结果页

显示命令行风格的扫描日志，包括：

- 扫描进度
- 发现的子域名/存活 URL
- 命中指纹
- POC 命中结果

### 指纹联动的 POC 结果页

会分成上下两个区域：

| 区域 | 显示内容 |
|---|---|
| **指纹识别结果（命中）** | URL、状态码、网页标题、命中的指纹名称。 |
| **POC 检测结果** | 命中的 POC 漏洞信息。 |

---

## 七、扫描报告保存在哪里？

每次扫描都会自动生成报告文件，保存在：

```
SilasGUI/silas_workspace/
```

- 按任务类型 + 时间戳命名文件夹。
- 可以在文件夹内找到 `*_report.json` 文件，里面是结构化结果。

一句话：**即使关闭了软件，也可以在 `silas_workspace` 里找到历史报告。**

---

## 八、常见问题与注意事项

| 情况 | 说明 |
|---|---|
| 输入 CIDR / IP 段后提示"目标数量过多" | 当目标超过 255 个 IP 时，软件会询问是否继续，防止大范围误扫。 |
| 批量文件里的 IP 被跳过 | 批量上传文件目前仅支持域名，文件中的 IP/CIDR 行会被跳过并在日志中提示。 |
| POC 任务无法重复启动 | 如果已有 POC 任务在运行，再次点击会提示"已有 POC 任务运行"，需先停止当前任务。 |
| 指纹识别失败或未命中 | 不会弹出 POC 联动窗口，只显示指纹结果。 |

---

## 九、快速上手示例

### 示例 1：扫描单个 IP 的指纹和 POC

1. 输入框填写：`192.168.77.123:8083`
2. 开启 **"指纹识别"** 开关。
3. 扫描完成后，弹窗选择 **"是"**。
4. 系统自动运行 POC 检测，结果页显示指纹命中和 POC 命中。

### 示例 2：扫描一个网段

1. 输入框填写：`192.168.77.0/24`
2. 如果 IP 数量超过 255，确认继续。
3. 开启 **"指纹识别"** 或 **"POC检测"** 开关。
4. 等待扫描完成查看结果。
